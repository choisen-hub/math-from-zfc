# math-from-zfc

**ZFC 공리로부터 수학 체계를 바텀업으로 구성하는 학습용 프로그램**

## 목적

이 프로그램은 수학의 토대인 ZFC(Zermelo-Fraenkel with Choice) 공리계로부터
출발하여, 대학 1학년 수준까지의 수학 체계를 한 단계씩 구성합니다.

코드 자체가 교과서 역할을 합니다. 각 모듈의 docstring을 읽는 것만으로
수학적 개념의 동기, 정의, 의미를 이해할 수 있도록 설계되었습니다.

## 설계 원칙

1. **해설 우선**: 코드보다 docstring이 더 중요합니다
2. **동기 우선**: 정의 전에 "왜 필요한가"를 먼저 설명합니다
3. **구체 → 추상**: 예시가 먼저, 정의가 나중입니다
4. **반사실적 사고**: "이것이 없으면 무엇이 깨지는가"를 보여줍니다
5. **연결**: 이전 Phase와의 관계를 명시합니다

## 전체 로드맵

```
Phase 0: 프로젝트 초기화
    ↓
Phase 1: ZFC 공리계 — 집합의 세계를 여는 규칙들
    ↓  (공집합, 짝, 합집합, 무한 공리 사용)
Phase 2: 자연수의 구성 — 무(無)에서 수를 만들기
    ↓  (재귀적 정의, 치환 공리꼴)
Phase 3: 자연수의 산술 — 덧셈과 곱셈을 정의하기
    ↓  (쌍의 동치류, 분류 공리꼴)
Phase 4: 정수의 구성 — 뺄셈의 한계를 넘기
    ↓  (같은 패턴, 곱셈으로 나눗셈 우회)
Phase 5: 유리수의 구성 — 나눗셈의 한계를 넘기
    ↓  (데데킨트 절단, 멱집합 공리)
Phase 6: 실수의 구성 — 유리수의 구멍을 메우기
    ↓  (패턴 추출, 추상화)
Phase 7: 대수 구조 — 반복되는 패턴을 추상화하기
    ↓  (완비성 → 극한 → 연속 → 미분)
Phase 8: 기초 해석학 — 극한과 연속성
    ↓
Phase 9: 전체 조감도 — 메타 수준의 성찰
```

## 의존 관계

- 각 Phase는 독립된 `.py` 파일입니다
- 각 파일은 **이전 파일만** import 가능합니다 (순환 의존 금지)
- 각 파일 끝에 `if __name__ == "__main__":` 블록으로 인터랙티브 데모가 포함됩니다

## 실행 방법

```bash
# 각 Phase를 독립적으로 실행 가능
python phase01_zfc_axioms.py
python phase02_natural_numbers.py
# ...

# 전체 의존 관계 시각화
python utils/dependency_graph.py
```
