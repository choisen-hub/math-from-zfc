Phase 1 ZFC 공리계

집합의 세계를 여는 규칙들

수학의 모든 것을 세우려면 출발점이 필요합니다. ZFC는 두 개의 원초적 개념에서 출발합니다:

  • 집합(set) — 정의하지 않는 기본 개념
  • 원소 관계(∈) — "x는 A의 원소이다"

이 두 개의 개념과 9개의 공리로부터 현대 수학의 거의 모든 것이 구성됩니다.

역사적 맥락

칸토어(Cantor)의 소박한 집합론은 "임의의 성질 P에 대해 {x : P(x)}는 집합이다"를 허용했습니다. 1901년, 러셀(Russell)은 이것이 모순을 낳음을 발견했습니다:

R = {x : x ∉ x}
R ∈ R이면 → R ∉ R (정의에 의해) → 모순!
R ∉ R이면 → R ∈ R (정의에 의해) → 모순!

체르멜로(Zermelo)가 1908년에 제한된 공리적 체계를 제안하여 역설을 피했고, 프렝켈(Fraenkel)이 보강하여 오늘날의 ZFC가 완성되었습니다.

1. 외연 공리 (Axiom of Extensionality)

∀A ∀B [ (∀x, x ∈ A ⟺ x ∈ B) → A = B ]

"두 집합이 같은 원소를 가지면 같다."

집합의 정체성은 오직 원소에 의해 결정됩니다. 정의 방식이나 나열 순서는 무관합니다.

  • {1, 2, 3} = {3, 1, 2} = {1, 2, 3, 2, 1}
  • {짝수인 소수} = {2} (정의 방식이 달라도 원소가 같으면 같다)
이 공리가 없으면? {1,2,3}과 {3,1,2}가 같은 집합인지 판단할 근거가 없습니다.

2. 공집합 공리 (Axiom of Empty Set)

∃∅ ∀x, x ∉ ∅

"원소가 하나도 없는 집합이 존재한다."

"아무것도 없음"이 존재해야 합니다! 공집합 ∅은 모든 것의 시작점입니다. Phase 2에서 이 ∅로부터 모든 자연수를 구성합니다.

  • ∅ = {} (원소 0개)
  • ∅ ≠ {∅} — 공집합과 "공집합을 담은 집합"은 다릅니다! ({∅}는 원소가 1개)
이 공리가 없으면? 출발점이 없습니다. 자연수를 구성할 씨앗이 없습니다.

3. 짝 공리 (Axiom of Pairing)

∀a ∀b ∃C ∀x [ x ∈ C ⟺ (x = a ∨ x = b) ]

"임의의 두 집합 a, b에 대해 {a, b}가 존재한다."

두 대상을 "하나로 묶는" 능력을 보장합니다. 이것으로 순서쌍을 구성합니다:

(a, b) = {{a}, {a, b}}     (쿠라토프스키 정의)

순서쌍이 없으면 함수를 정의할 수 없고, 함수가 없으면 수학의 대부분이 무너집니다.

이 공리가 없으면? {∅}조차 만들 수 없어 자연수 1을 구성할 수 없습니다.

4. 합집합 공리 (Axiom of Union)

∀F ∃U ∀x [ x ∈ U ⟺ ∃A(A ∈ F ∧ x ∈ A) ]

"집합들의 집합이 주어지면, 모든 원소를 합칠 수 있다."

후계자 함수 S(n) = n ∪ {n}에서 합집합 연산이 필수적입니다.

  • ∪{{1,2}, {2,3}, {3,4}} = {1, 2, 3, 4}
  • S(2) = {0,1} ∪ {2} = {0,1,2} = 3
이 공리가 없으면? n ∪ {n}을 만들 수 없어 후계자를 구성할 수 없습니다.

5. 멱집합 공리 (Axiom of Power Set)

∀A ∃P ∀B [ B ∈ P ⟺ B ⊆ A ]

"어떤 집합의 모든 부분집합을 모은 집합이 존재한다."

|A| = n이면 |P(A)| = 2n. 칸토어가 증명한 것: |A| < |P(A)| — 무한에도 크기가 다른 단계가 있습니다.

  • P(∅) = {∅} — 크기 1
  • P({a}) = {∅, {a}} — 크기 2
  • P({a,b}) = {∅, {a}, {b}, {a,b}} — 크기 4
이 공리가 없으면? 실수를 구성할 수 없고, 대각선 논증도 불가능합니다.

6. 분류 공리꼴 (Axiom Schema of Separation)

∀A ∃B ∀x [ x ∈ B ⟺ (x ∈ A ∧ φ(x)) ]

"이미 있는 집합에서 조건을 만족하는 원소만 골라낼 수 있다."

러셀의 역설을 차단하는 핵심 장치입니다:

소박한 집합론: {x : φ(x)} — 아무 조건이나 집합을 만든다 → 역설!
ZFC: {x ∈ A : φ(x)} — 기존 집합에서 걸러낸다 → 안전!

7. 치환 공리꼴 (Axiom Schema of Replacement)

A가 집합이고 F가 함수이면, F[A] = {F(x) : x ∈ A}도 집합이다

"집합의 각 원소를 함수로 변환한 결과도 집합이다."

Phase 3에서 덧셈/곱셈의 재귀적 정의가 실제로 함수를 만들어내는 것을 보장합니다.

8. 무한 공리 (Axiom of Infinity)

∃I [ ∅ ∈ I ∧ ∀x(x ∈ I → x ∪ {x} ∈ I) ]

"자연수 전체를 포함하는 무한 집합이 존재한다."

다른 공리들로 0, 1, 2, ... 를 각각 만들 수 있지만, {0, 1, 2, 3, ...} 전체가 하나의 집합인지는 별도의 공리가 필요합니다.

"각각의 n을 만들 수 있다" ≠ "전부를 모은 것이 존재한다" — 유한 → 무한의 점프에는 별도의 공리가 필요합니다.

9. 선택 공리 (Axiom of Choice)

∀F [ (∀A ∈ F, A ≠ ∅) → ∃f: F → ∪F, ∀A ∈ F, f(A) ∈ A ]

"비어있지 않은 집합들의 모임에서, 각 집합에서 하나씩 고를 수 있다."

직관적으로 당연해 보이지만 논란이 많았습니다. 바나흐-타르스키 역설: 선택 공리를 인정하면 하나의 구를 분해하여 같은 크기의 구 두 개를 만들 수 있습니다!

이 프로그램의 Phase 2-8에서는 선택 공리를 명시적으로 사용하지 않습니다.
요약: 이 9개의 공리가 수학이라는 건물의 기초 전부입니다. 이 위에 자연수, 정수, 유리수, 실수, 함수, 공간을 모두 세울 것입니다.

Phase 2 자연수의 구성

무(無)에서 수를 만들기 — 폰 노이만 서수

자연수는 직관적으로 당연한 것처럼 느껴지지만, ZFC에서는 그 존재를 구성해야 합니다. 놀랍게도 공집합 하나로 모든 자연수를 만들 수 있습니다!

폰 노이만 구성 (Von Neumann Construction)

0 = ∅ = {}                             ← 아무것도 없음
1 = {∅} = {0}                          ← 0을 담은 집합
2 = {∅, {∅}} = {0, 1}                  ← 0과 1을 담은 집합
3 = {∅, {∅}, {∅, {∅}}} = {0, 1, 2}    ← 0, 1, 2를 담은 집합
...
n+1 = n ∪ {n}                          ← 후계자 함수
핵심 관찰: 각 자연수 n의 원소 개수가 정확히 n개입니다. 집합 자체가 자신의 "크기"를 인코딩합니다!

순서 관계의 우아함

폰 노이만 구성의 놀라운 성질:

n < m  ⟺  n ∈ m    ← 원소 관계가 곧 엄격 순서!
n ≤ m  ⟺  n ⊆ m    ← 부분집합 관계가 곧 순서!

별도의 "순서" 개념을 정의할 필요 없이, 집합의 구조가 그대로 순서가 됩니다.

인터랙티브: 폰 노이만 서수

자연수를 입력하면 집합 표현을 보여줍니다.

3 = {∅, {∅}, {∅, {∅}}} 즉, 3 = {0, 1, 2} 원소 수: |3| = 3 (집합 자체가 크기를 인코딩!)

사용된 ZFC 공리

공리역할
공집합 공리0 = ∅의 존재
짝 공리{n}을 구성하기 위해
합집합 공리n ∪ {n}을 계산하기 위해
무한 공리{0, 1, 2, ...} 전체가 집합으로 존재
우리는 방금 ZFC의 공리 4개만으로 자연수 전체를 구성했습니다. 라이프니츠가 꿈꿨던 "무에서 수를 만들기"가 실제로 작동하는 것입니다.

Phase 3 자연수의 산술

덧셈과 곱셈을 정의하기

자연수라는 대상을 만들었으니, 이제 연산을 정의합니다. "1 + 1 = 2"가 참인 이유를 공리적으로 정당화합니다.

덧셈의 재귀적 정의

n + 0    = n           ← 기저 조건: 0을 더하면 변하지 않는다
n + S(m) = S(n + m)    ← 재귀 단계: 후계자를 더하면 결과의 후계자

2 + 3의 계산 과정:

2 + 3 = 2 + S(2)       ← 3 = S(2)
      = S(2 + 2)       ← 재귀 단계
      = S(2 + S(1))    ← 2 = S(1)
      = S(S(2 + 1))    ← 재귀 단계
      = S(S(2 + S(0))) ← 1 = S(0)
      = S(S(S(2 + 0))) ← 재귀 단계
      = S(S(S(2)))     ← 기저 조건
      = S(S(3)) = S(4) = 5

곱셈의 재귀적 정의

n × 0    = 0           ← 기저: 0을 곱하면 0
n × S(m) = n × m + n   ← 재귀: 덧셈의 반복
패턴: 후계자 → 덧셈 → 곱셈. 각 연산은 이전 연산의 "반복 적용"입니다.

기본 성질 (귀납법으로 증명)

성질내용
교환법칙n + m = m + n,   n × m = m × n
결합법칙(n + m) + k = n + (m + k),   (n × m) × k = n × (m × k)
분배법칙n × (m + k) = n × m + n × k
순서와 연산n ≤ m ⟺ ∃k, n + k = m

Phase 4 정수의 구성

뺄셈의 한계를 넘기 — 자연수 쌍으로 정수 만들기

자연수에서 3 - 5는 정의되지 않습니다. 음수를 전제할 수 없으므로, 이미 가진 것(자연수)만으로 정수를 구성해야 합니다.

핵심 아이디어

(a, b)라는 자연수 쌍을 "a - b를 의미하는 것"으로 해석합니다.
뺄셈을 직접 하는 대신, "빼고 싶다는 의도"를 기록합니다.

(3, 5)와 (0, 2)와 (1, 3)은 모두 같은 정수 -2를 의미합니다. 따라서 동치 관계가 필요합니다:

(a, b) ~ (c, d) ⟺ a + d = b + c

왜 뺄셈이 아니라 덧셈으로 정의하는가?

뺄셈은 아직 정의되지 않았기 때문입니다! Phase 3에서 정의한 자연수 덧셈만 사용합니다.

동치류로서의 정수

정수 -2 = {(0,2), (1,3), (2,4), (3,5), ...}  ← 모두 같은 정수
정수  0 = {(0,0), (1,1), (2,2), (3,3), ...}
정수 +3 = {(3,0), (4,1), (5,2), (6,3), ...}

연산 정의

덧셈: (a,b) + (c,d) = (a+c, b+d)
곱셈: (a,b) × (c,d) = (ac+bd, ad+bc)
역원: -(a,b) = (b,a)
그리고 드디어...
뺄셈: a - b = a + (-b)    ← 우리가 뺄셈을 하려고 이 모든 것을 구성했다!

자연수의 매장

자연수 n → 정수 (n, 0). 이 매장은 덧셈과 곱셈을 보존합니다. "자연수가 정수 안에 살고 있다."

나눗셈의 한계를 넘기 — 정수 쌍으로 유리수 만들기

정수에서 3 ÷ 2는 정의되지 않습니다. Phase 4와 정확히 같은 전략을 씁니다:

체(Field)의 구조

유리수 ℚ는 사칙연산이 자유롭게 가능한 첫 번째 체계입니다! (0으로 나누는 것만 제외)

유리수의 조밀성

두 유리수 사이에 항상 또 다른 유리수가 있습니다. "유리수는 빈틈없이 촘촘해 보입니다"

√2의 비합리성 증명

정리: √2는 유리수가 아니다 (귀류법)

√2 = a/b (a, b는 서로소)라고 가정하면:

a² = 2b²
→ a²이 짝수 → a가 짝수 → a = 2k
→ (2k)² = 2b² → 4k² = 2b² → b² = 2k²
→ b²이 짝수 → b도 짝수
→ a, b 모두 짝수 → 서로소에 모순!
∎
유리수에는 보이지 않는 구멍이 있습니다. 이 구멍을 메우는 것이 Phase 6의 목표입니다.

Phase 6 실수의 구성

유리수의 구멍을 메우기 — 데데킨트 절단

유리수는 조밀하지만 "구멍"이 있습니다. 실수는 이 구멍을 전부 메운 체계입니다.

데데킨트 절단 (Dedekind Cut)

"유리수 전체를 두 부분으로 자르는 방법이 곧 실수이다."

절단 = 유리수 전체를 두 집합 (L, R)로 나누는 것
조건: L의 모든 원소 < R의 모든 원소, L에 최대원소 없음

유리수 3/2의 절단

L = {q ∈ ℚ : q < 3/2}
R = {q ∈ ℚ : q ≥ 3/2}
→ R에 최소원소 3/2가 있음. 유리수에 해당하는 절단.

√2의 절단

L = {q ∈ ℚ : q < 0 또는 q² < 2}
R = {q ∈ ℚ : q > 0 이고 q² ≥ 2}
→ R에 최소원소가 없음! 무리수에 해당하는 절단.

실수의 완비성 (상한 성질)

"위로 유계인 비어있지 않은 실수 집합은 상한을 가진다."

유리수에서는 성립하지 않습니다: S = {q ∈ ℚ : q² < 2}의 상한은 √2이지만, √2 ∉ ℚ!

실수에서는 √2 ∈ ℝ이므로 상한이 존재합니다. 이것이 해석학 전체의 토대입니다.

칸토어의 대각선 논증

실수는 자연수보다 "더 많습니다": |ℕ| < |ℝ|

[0,1)의 실수를 나열했다고 가정:
  r₁ = 0.3 1 4 1 5 ...
  r₂ = 0. 7 1 8 2 8 ...
  r₃ = 0. 2 8 1 8 2 ...
  r₄ = 0. 1 4 1 4 2 ...

대각선: 3, 1, 1, 4, ...
새 수:  4, 2, 2, 5, ... → x = 0.4225...

x ≠ rₙ (모든 n에 대해 n번째 자리가 다름)
→ 어떤 나열도 불완전하다!
→ 무한에도 크기가 다른 단계가 있다!
연속체 가설: |ℕ|과 |ℝ| 사이에 다른 크기의 무한이 있는가? 괴델(1940)과 코헨(1963)이 증명: 이 질문은 ZFC로는 답할 수 없다!

Phase 7 대수 구조

반복되는 패턴을 추상화하기 — 군, 환, 체

Phase 2-6에서 반복된 패턴: 집합 + 연산 + 결합법칙 + 항등원 + 역원. 이 패턴 자체를 연구하는 것이 추상대수학입니다.

군 (Group)

집합 G와 연산 · 의 쌍 (G, ·)이 다음을 만족할 때:

  1. 결합법칙: (a · b) · c = a · (b · c)
  2. 항등원: ∃e, e · a = a · e = a
  3. 역원: ∀a, ∃a⁻¹, a · a⁻¹ = e
  • (ℤ, +) — Phase 4에서 구성! 항등원: 0, 역원: -n
  • S₃ — 정삼각형의 대칭군 (6개 원소, 비가환!)
  • ℤ/nℤ — 시계 산술

환 (Ring)

덧셈 아벨군 + 곱셈 결합법칙 + 분배법칙. 예: (ℤ, +, ×) — Phase 4에서 구성한 것!

체 (Field)

환 + 곱셈 역원(0 제외). 예: ℚ (Phase 5), ℝ (Phase 6). "체에서는 사칙연산이 자유롭다."

구조 보존 사상 (Homomorphism)

ℕ ──→ ℤ ──→ ℚ ──→ ℝ
n ↦ (n,0)  z ↦ z/1  q ↦ 절단

각 매장은:
  f(a + b) = f(a) + f(b)   ← 덧셈 보존
  f(a × b) = f(a) × f(b)   ← 곱셈 보존
추상화의 위력: "항등원은 유일하다"를 군 수준에서 한 번 증명하면, 모든 군에 자동으로 적용됩니다.

Phase 8 기초 해석학

극한, 연속성, 미분 — 실수의 완비성이 열어주는 세계

실수를 구성한 진짜 이유는 해석학을 하기 위해서입니다. 뉴턴과 라이프니츠의 미적분을 200년 후 코시와 바이어슈트라스가 ε-δ 정의로 엄밀화했습니다.

극한의 ε-N 정의

lim(n→∞) aₙ = L  ⟺  ∀ε > 0, ∃N ∈ ℕ, ∀n > N: |aₙ - L| < ε

"아무리 작은 오차 범위(ε)를 잡아도, 어느 시점(N) 이후로는 수열이 그 범위 안에 들어온다."

예시: aₙ = 1/n → 0

εN의미
0.110n > 10이면 1/n < 0.1
0.01100n > 100이면 1/n < 0.01
0.0011000n > 1000이면 1/n < 0.001

단조수렴정리 (완비성 필수!)

단조증가이고 위로 유계인 수열은 수렴한다.

유리수에서의 반례: aₙ = √2의 n자리 근사 (유리수)
단조증가 ✓, 위로 유계 ✓, 하지만 극한 √2 ∉ ℚ!
→ 실수의 완비성 없이는 이 정리가 성립하지 않습니다.

함수의 연속성 (ε-δ 정의)

f가 x = a에서 연속  ⟺  ∀ε > 0, ∃δ > 0, ∀x: |x - a| < δ → |f(x) - f(a)| < ε

"입력을 조금 바꾸면, 출력도 조금만 바뀐다."

미분

f'(x) = lim(h→0) [f(x+h) - f(x)] / h

예시: (x²)' = 2x

f'(x) = lim(h→0) [(x+h)² - x²] / h
      = lim(h→0) [2xh + h²] / h
      = lim(h→0) (2x + h)
      = 2x

의존 사슬: ZFC 공리 → 실수(완비) → 극한 → 연속 → 미분

f'(x) = 2x라는 간단한 결과 뒤에, ZFC로부터 시작된 긴 구성의 사슬이 있습니다.

반복된 패턴

1. "확장" 패턴: 이전 체계의 한계 → 쌍의 동치류 → 새 체계
   ℕ→ℤ: 뺄셈 불가 → 자연수 쌍의 동치류
   ℤ→ℚ: 나눗셈 불가 → 정수 쌍의 동치류
   ℚ→ℝ: 구멍 존재 → 데데킨트 절단

2. "매장" 패턴: 이전 체계가 새 체계 안에 보존적으로 포함
   ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ

3. "추상화" 패턴: 구체적 예시에서 공통 구조 추출 (군, 환, 체)
